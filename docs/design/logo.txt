# Hildi empty-session mark -- EDITABLE PICTURE

This is the ONE file to edit. Run `make logo` and the Pascal arrays in
`src/tui/widgets/TUIWidgetsChatPanel.pas` regenerate.

It is a PLAIN ASCII PIXEL GRID: 86 columns wide, 28 rows tall, one character per
pixel. Each braille cell in the terminal is a 2x4 block of these pixels, so:

    .   blank
    #   ink, MUTED   -- the circle around the h (the frame of the mark)
    W   ink, BRIGHT  -- the word "hildi"

Everything is monospace ASCII, so the picture lines up in any editor: vim, emacs,
nano, or a plain text window. Nothing here needs a braille font.

## Editing

- Move art by editing the '#' and 'W' characters. To nudge a row left, delete its
  leading '.' and add one '.' at the end so the row stays 86 wide.
- Change a letter's tone by swapping 'W' with '#' (or back).
- Rows must all be exactly 86 characters. `make logo` refuses to write and tells
  you which row is wrong, so a paste that reflows cannot silently corrupt the art.
- '86' columns is 43 terminal cells, which is what the panel centres.
