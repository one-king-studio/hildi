Why only two hints

Every line must name a key that does something from this screen. Ctrl+? lists commands was removed: no handler for it exists anywhere in the app. This text is descriptive prose, so it is uniformly muted and keeps sentence case — it is not chrome.

Narrow panesthe label yields, never the hints

The hint budget is taken first — it is the fixed, known-length part — and the label takes what remains, clamped by display cells. Before this rule a long caption silently pushed the hints out of the row, and the text block clips them mid-word, so there was nothing visibly broken enough to report.

The caption is cut at TU and the hint still reads in full. With no room at all the label is dropped rather than clipped to a fragment, because a state cut to two characters says nothing.

Reasoning caption rotationpsThinking only

While the agent reasons the caption rotates every 2.6 s: Thinking → Reasoning → Working it out → Considering → Pondering. The word is derived from the clock, not a per-frame counter, so a dropped frame cannot desynchronise it, and entering the state resets the origin — every turn starts on “Thinking”.

Only psThinking rotates. A tool run, an approval or an error states a fact and must not be decorated.

Clamped at 48 display cells, keeping the tail: the end of a path or command identifies it. The cut prefers a path separator so the result reads as a path rather than a chopped stem. Malformed arguments still caption — model output is frequently truncated mid-call, and the tool is running.

Command paletteactionable entries only

Opens while the composer holds a lone /token. Entries are appended, never pre-sized — an omitted command is absent, not a blank / row. Esc dismisses it and leaves the typed / alone, so a prompt may start with a slash.

CommandOffered when
/sessionsalways — it only reads the store
/newa workspace exists (ConnState ≠ csIdle)
/checkpointa runtime is attached (Driver ≠ nil)
/undoa turn exists that is not already undone
/redoan undone turn sits above the redo floor
/revertat least two live turns

The palette is rebuilt on every connect-state and ledger change. It is populated during construction — before the connect state is known — so anything conditional is stale until something resyncs it.

Sidebar — the subagent listshown in the composer's place

Toggled with ctrl+d when the session has subagents. It takes the composer's place and the composer's chrome, with one deliberate difference: the border is amber (Warn), because this is not the prompt — work in flight, not yours to type into.

Each row is the child's label plus its current turn title, so the list says what each agent is doing. The selected child loads into the stream; there is no prompt here, so the view is read-only.

KeyAction
ctrl+aabort the selected child
ctrl+rrelease it (keeps running, detaches)
ctrl+ppromote it to its own session
enterspy — no child selected

Chords, never bare letters: the list has focus while a child streams, exactly when the operator is most likely to be typing at something else, and a stray a would abort real work.

Not yet captured, and not yet two-tone. This surface is not in the capture harness yet, and its CTAs are painted as one uniformly amber string. The two-tone rule (dim key, brighter action) is not applied here — the shared splitter exists, but the sidebar does not call it.
