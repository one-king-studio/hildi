TUI Design Language v0 · first pass

Glyphs, motion, colour, and layout for the hildegard-helper terminal UI. Self-contained; no external assets.

Diagrams render in one monospace font with ligatures disabled and whitespace preserved. Box-drawing alignment needs a font that includes U+2500–U+257F (Menlo, DejaVu Sans Mono, JetBrains Mono, Cascadia Mono all do).

Borders

One weight per nesting level. Light is the default; heavy for emphasis/active; rounded for softer panels; dashed for separators.

Loaders

Cadence ~80–120 ms. One timer per app; pause when hidden. Prefer braille; fall back to the line spinner. Braille has no 1-cell monospace font on macOS, so each spinner occupies a fixed cell width here to keep rows aligned.
